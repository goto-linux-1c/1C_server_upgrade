# Скрипт корректного обновления серверной части платформы 1С:Предприятие

Bash-скрипт для корректного обновления серверной части платформы 1С:Предприятие.

Скрипт сохраняет и восстанавливает настройки служб сервера 1С и ras (даже если их несколько на одном сервере), изменяет версию платформы во всех веб-публикациях и выполняет ещё много полезных мелочей, не включённых в штатный инсталлятор.

Иными словами — **«обновление под ключ»** или **«нажал и забыл»**.

## Проблема

Установщики платформы 1С от вендора для Linux (и для Windows тоже) — как в виде пакетного менеджера, так и в виде программы установки, сделанной на VMWare InstallBuilder — не умеют и, скорее всего, не будут уметь сохранять настройки службы сервера 1С, сделанные вручную. Особенно если серверов 1С несколько на разных портах на одном логическом сервере.

Тем более они не умеют обновлять версии платформы во всех веб-публикациях.

Для не совсем внимательного пользователя это может быть проблемой. Тем более если этот пользователь работает на Linux.

## Что делает скрипт

- Проверяет, что запущен с правами администратора.
- Проверяет наличие архива установки или распакованного файла установки.
- Если выбрано обновление — проверяет соответствие установленной версии платформы и заданной ключом командной строки.
- Сохраняет файлы старых служб сервера 1С и ras с возможными нетиповыми настройками.
- Создаёт новые файлы служб сервера 1С и ras с перенесёнными настройками.
- Останавливает службы сервера 1С и ras.
- Устанавливает новую версию платформы 1С.
- Переносит в её каталог новые файлы служб сервера 1С и ras.
- Запускает службы сервера 1С и ras.
- При успешном запуске удаляет старую версию платформы 1С.
- Во всех найденных веб-публикациях изменяет версию платформы 1С.
- Перезапускает веб-сервер.

Скрипт может обновлять 8.3.х.х на 8.5.х.х и обратно, что не менее актуально в настоящий момент (см. багтрекер 1С).

## Использование

```bash
Использование скрипта: $PROGNAME параметр1 параметр2
Первый параметр это номер обновляемой версии 1С, если 0 то чистая установка
Второй параметр это номер новой версии 1С
Файл установки 1С должен находиться в одном каталоге со скриптом
Если указан номер обновляемой версии 1С, то должен существовать каталог установки обновляемой версии 1С
Пример: $PROGNAME 0 8.3.24.1586
Пример: $PROGNAME 8.3.23.1586 8.3.24.1586
